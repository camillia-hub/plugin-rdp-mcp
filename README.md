# RDP MCP

Drives a Windows machine over Remote Desktop. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/mcp-rdp

Installs from the Camillia hub as `rdp-mcp-f7aeda`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
